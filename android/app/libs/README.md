# Bundled Apex Android SDK

The `debug` and `release` folders contain the complete modular Apex Android SDK
version `1.0.0-SNAPSHOT` used by this Flutter demo.

Android Archive (`.aar`) files are used instead of plain Java archives because
the SDK includes Android manifests, resources, and UI components. Gradle selects
the matching folder for each Flutter build variant.

Included modules: core, banner, interstitial, native, conversational, video,
in-app bidding, app-open, and wallet.
